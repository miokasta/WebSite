# MIOKASTA artist website

First working version of the official MIOKASTA artist website — a responsive, static one-page experience built with HTML, CSS and vanilla JavaScript.

## Preview

Open `index.html` in a browser. No build step or dependencies are required.

## Content

- Hero and featured DARKAI release
- Music carousel featuring ALIVE, ELECTRICITY, HEY MR DJ and ONLY RHYTHM
- Artist story and live / DJ booking section
- Newsletter interaction and social links
- Responsive navigation, scroll reveals and accessible reduced-motion support

Spotify, Beatport and social links are placeholders ready to be replaced with final URLs.
